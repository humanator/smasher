How a workflow runs

  1. It begins at Start and runs one step at a time.
  2. When a step finishes, a connection decides what runs next. Rules on connections can look at how the step went.
  3. Steps can ask a person, call an AI model, or run a tool. Results are saved so later steps can use them.
  4. It ends when it reaches a Finish step.
